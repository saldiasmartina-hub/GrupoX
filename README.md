## Cómo ejecutarlo
Requiere Python 3. Desde la carpeta del repositorio:

```bash
python main.py
```

El programa muestra algunos préstamos y devoluciones y termina con
`¡Todas las pruebas pasaron!`.

## Archivos
- `libro.py`: clase `Libro`
- `socio.py`: clase `Socio`
- `biblioteca.py`: clase `Biblioteca`
- `main.py`: demostración + pruebas automáticas
